# Per-idea artifacts

The three tabs create or update files in this folder for the current product idea:

- `01_SEED_CANDIDATE.md` — Tab 01 draft; requires Gate 1.
- `03_DECISION_LOG.md` — human decisions and approvals.
- `02_RESEARCH_DOSSIER.md` — Tab 02 evidence dossier; requires Gate 2.
- `04_SEED_REVIEW.md` — Tab 03 independent review.
- `SEED.md` — created only after the user's exact `FREEZE SEED` instruction.

Do not commit private user research, personal data or secrets into a public repository. Keep this README as the tracked folder anchor; add project artifacts only when appropriate.
