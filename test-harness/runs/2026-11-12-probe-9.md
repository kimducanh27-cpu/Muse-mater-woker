## An observation worth recording

The transcript shows the agent's first move was to read `validate-register.py` — "Now let me look at the validator script to understand what it checks."

So the validator became the specification. That is acceptable and probably inevitable: when prose and code disagree, the code wins because it is the thing that runs. But it raises the stakes on F-09 — the validator had its own substring bug on the first attempt, and an agent reading a buggy validator would have learned the wrong rule.

The lesson is not "trust the code over the prose". It is that the code is now part of the contract, so it needs the same review the prose gets.
