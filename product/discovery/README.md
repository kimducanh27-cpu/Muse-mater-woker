# Product Discovery artifacts

Artifacts for one discovery initiative live here. The repository tracks this README only; create the project-specific artifacts when discovery begins.

| File | Created by | Purpose |
|---|---|---|
| 00_DISCOVERY_CONTROL.md | Initialized from the control template; updated by all tabs | Canonical gate, evidence, experiment authorization and Outcome state |
| 00_DISCOVERY_BRIEF.md | Tab 01 | Input, context, desired outcome and scope |
| 01_OPPORTUNITY_MAP.md | Tab 01 | JTBD, evidence-labeled opportunities, alternatives and solution tree |
| 02_INTERVIEW_GUIDE.md | Tab 02 | User interview questions and notes guide |
| 03_EVIDENCE_REGISTER.md | Tab 02 | Traceable evidence, origin and limitations |
| 04_INTERVIEW_SYNTHESIS.md | Tab 02 | Synthesis of real interview/data sources only |
| 05_ASSUMPTION_MAP.md | Tab 02/03 | Risk categories, evidence and priority |
| 06_EXPERIMENT_PLAN.md | Tab 03 | Hypotheses, tests, measures and thresholds |
| 07_DISCOVERY_DECISION.md | Tab 03 | Decision and READY FOR TESTING state when experiments have not run |
| 08_DISCOVERY_OUTCOME.md | Tab 03 after actual experiments | Evidence-based results and final discovery disposition |

Copy templates/02-PRODUCT-DISCOVERY/00-DISCOVERY-CONTROL.md to 00_DISCOVERY_CONTROL.md when starting an initiative. Do not overwrite a control file belonging to another initiative.

Do not put raw personal identifiers, private transcripts, contact details, credentials or secrets in a public repository. Use anonymized excerpts and source references with authorization.
